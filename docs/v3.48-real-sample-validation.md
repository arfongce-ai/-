## 수정한 문제

1. 디코딩되지 않은 영상이 분석되는 문제
   - 실제 첫 프레임, 해상도, readyState를 모두 확인한 뒤 분석 버튼을 활성화한다.
   - HEVC 표시 지원 여부 문자열만 믿지 않고 실제 디코딩 성공 여부를 확인한다.

2. 영상 근거가 없는 연결 장면의 과신
   - 포즈 샘플이 없으면 연결 신뢰도를 낮음으로 제한한다.
   - 두 동작의 속도 정점이 2개로 분리되지 않으면 연결 신뢰도를 높음으로 올리지 않는다.
   - 의미 규칙만으로 묶은 경우와 영상 시간·속도 근거가 있는 경우를 구분한다.

3. 복합동작 내부 단계의 과도한 정밀 표현
   - 14-1~14-4, 16-1~16-4의 시각은 모두 추정값으로 표시한다.
   - 움직임 보조 추정과 장면 길이 비율 추정을 구분해 기록한다.

4. 번호와 장면 표시 통일성
   - 공식 동작 수 18개와 분석 단위 20개를 분리한다.
   - 기합 장면은 20번이 아니라 `기합`으로 표시한다.

- 연결 장면 통합은 설명 단위이며 공식 동작 번호를 없애지 않는다.
