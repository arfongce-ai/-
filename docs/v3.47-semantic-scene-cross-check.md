# v3.47 연결동작·복합동작 장면 통합 교차검증

## 적용 범위

- 태극 1장 5~6번: 같은 앞굽이를 유지하는 아래막기 → 몸통지르기
- 태극 1장 11~12번: 같은 앞굽이를 유지하는 아래막기 → 몸통지르기
- 태극 1장 14번·16번: 앞차기 → 회수 → 착지 → 몸통지르기 복합동작

## 설계 원칙

- 연결 장면의 존재는 품새별 의미 규칙으로 고정하여 정면·측면·대각선 분석의 장면 순서를 통일한다.
- 실제 영상의 중간 정지 시간, 속도 정점, 하체 안정 지표, 관절 감지 품질은 연결 설명과 신뢰도에 반영한다.
- 연결 장면은 첫 동작 기준으로 평가하지 않는다. 하체 유지, 기술 전환, 마지막 지르기 마무리를 중심으로 설명한다.
- 연결 장면의 개별 동작 감점은 자동 확정하지 않고 지도자 확인으로 남긴다.
- 14-1~14-4와 16-1~16-4는 앱 분석용 내부 단계이며 공식 품새 동작 번호가 아니다.

## 자동 검증

```text
npm run verify:cross
npm run test:engine
npm run test:mapping
npm run test:boundary
npm run test:semantic
npm run test:all
```

`test:semantic`은 다음을 확인한다.

- 빠른 막기·지르기 연결 장면에서 움직임 정점 두 개가 유지되는지
- 중간 정지가 길어지면 연결 신뢰도가 낮아지는지
- 적응형 연결 시간 기준이 안전 범위를 지키는지
- 복합동작 내부 단계 네 개가 장면 안에서 시간 순서대로 배치되는지

## 실영상 검증 권장

- 태극 1장 영상에서 5~6번과 11~12번이 각각 한 장면으로 표시되는지 확인한다.
- 각 연결 카드의 중간 정지 추정 시간과 연결 신뢰도가 실제 수행 느낌과 맞는지 지도자가 확인한다.
- 14번과 16번 카드에서 내부 단계가 공식 번호가 아닌 앱 분석용으로 안내되는지 확인한다.
- 일부러 막기와 지르기 사이를 길게 멈춘 영상에서 연결 신뢰도가 낮아지는지 확인한다.
