# 품새 자세 명칭 점검 보고 (v3.62)

## 요약
태극1장을 제외한 **16개 품새 모두**, 코드의 기술명(`techniques`) 배열에 들어 있는
'본동작' 수가 공식 동작 수보다 **1~5개 부족**합니다.

원인: 각 품새의 `count` 값과 `techniques` 배열 길이는 *준비서기·기합·마무리·확인 메모를
포함한 전체 항목 수*에 맞춰져 있습니다. 그런데 앱은 동작 번호를 매길 때 이 비(非)동작 항목을
제외합니다. 따라서 화면에는 "공식 N개 동작"이 정확히 표시되지만, **실제 이름이 붙은 본동작은
N보다 적어** 동작 이름이 공식 번호와 한 칸씩 어긋날 수 있습니다.

앱은 이 불일치를 콘솔 경고로 알리고(`[품새 데이터] … 본동작 X개, 공식 Y개`),
리포트에 "지도자 검수 권장"을 명시하므로 **오류로 멈추지는 않습니다.** 다만 정확한
동작별 이름을 위해서는 아래 부족분을 국기원/KTA 교본 기준으로 보충해야 합니다.

## 권장 작업 (지도자/교본 검수)
1. 위 표의 '부족' 수만큼, 각 품새의 진짜 본동작이 무엇인지 국기원 교본·KTA 자료로 확인합니다.
   - 부족분 대부분은 '기합'이 마지막 본동작과 같은 동작에 겹쳐 있거나(예: 18번 지르기+기합),
     준비/마무리 동작이 본동작 자리를 차지해 생깁니다.
2. `techniques` 배열에 **번호 동작만** 공식 순서대로 넣고, 기합·준비·마무리는 메모로 분리하면
   본동작 수가 공식과 정확히 일치합니다(태극1장의 `movements` 구조가 모범 사례).
3. 좌/우, 서기 종류(앞서기·앞굽이·범서기·뒷굽이 등), 막기·지르기 표기는 교본 도해와 한 동작씩
   대조해 확정하길 권장합니다. 현재 데이터의 `note`에도 "이미지 참고 / 지도자 검수 필요"로
   명시되어 있습니다.
